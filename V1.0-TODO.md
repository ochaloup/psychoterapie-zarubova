## Phase 2 — Domain cutover (DNS)

This is the riskiest step because the domain is currently in use by the existing site. Follow `PLAN.md` §6.2 and `IMPLEMENTATION-PLAN.md` §11 in full. Summary:

- [ ] Identify current host (`dig +short psychoterapie-zarubova.cz` and `dig MX psychoterapie-zarubova.cz`).
- [ ] **Screenshot every existing DNS record** before changing anything. MX especially — if Barbora's email is routed through this domain we must not break it.
- [ ] Reduce TTL on the records that will change to 300 s several hours before the cutover.
- [ ] Replace apex `A` records with the four GitHub Pages apex IPs (`PLAN.md` §6.2 table). Cross-check the IPs against [GitHub's docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) at the time of cutover.
- [ ] Set `www` CNAME → `ochaloup.github.io.` (note trailing dot).
- [ ] Add Resend's SPF + DKIM records from Phase 1.
- [ ] **Do not** modify MX records unless email is being migrated (not planned).
- [ ] Verify: `dig +short psychoterapie-zarubova.cz` returns the four GitHub IPs; `dig +short www.psychoterapie-zarubova.cz` returns `ochaloup.github.io.`.
- [ ] Verify in Resend dashboard: domain is now **Verified** (green badge).

**Gate:** DNS resolves to GitHub Pages, Resend is verified, MX records are untouched. Rollback path: restore screenshotted records (TTL 300 s, so ~10 min worst case).

## Phase 4 — Cloudflare Worker + contact form

Follows `PLAN.md` §7 in full. Summary:

- [ ] Sign up at https://cloudflare.com (free tier).
- [ ] Create `worker/` directory at repo root with `wrangler.toml`, `package.json`, `src/index.ts` (source in `PLAN.md` §7.4).
- [ ] `cd worker && pnpm install`.
- [ ] `pnpm exec wrangler login`.
- [ ] `pnpm exec wrangler kv namespace create RL` → paste returned ID into `wrangler.toml`.
- [ ] `pnpm exec wrangler secret put RESEND_API_KEY` → paste the Resend key from Phase 1.
- [ ] In `wrangler.toml`, set `ALLOWED_ORIGIN = "https://psychoterapie-zarubova.cz"`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL`.
- [ ] `pnpm exec wrangler deploy` → capture the `*.workers.dev` URL it prints.
- [ ] Save that URL as `PUBLIC_CONTACT_ENDPOINT` in two places:
  - Local `.env` (gitignored): `PUBLIC_CONTACT_ENDPOINT=https://...workers.dev`
  - GitHub: repo Settings → Secrets and variables → Actions → **Variables** (not Secrets) → `PUBLIC_CONTACT_ENDPOINT`
- [ ] Wire the real `fetch()` call into `src/components/ContactForm.astro`. Replace the `await new Promise(r => setTimeout(r, 800))` with the real submit per `PLAN.md` §7.6. Keep the same field names (`name`, `email`, `message`, `hp`) so the Worker accepts the body unchanged.

**Verify the Worker (before merging the form change):**

```
# rejects bad origin
curl -i -X POST <worker-url> -H 'Origin: https://evil.example' -H 'Content-Type: application/json' --data '{}'
# → expect 403

# accepts site origin with valid body
curl -i -X POST <worker-url> -H 'Origin: https://psychoterapie-zarubova.cz' -H 'Content-Type: application/json' --data '{"name":"Test","email":"chalda@marinade.finance","message":"hello"}'
# → expect 200, email arrives

# honeypot silently drops
curl -i -X POST <worker-url> -H 'Origin: https://psychoterapie-zarubova.cz' -H 'Content-Type: application/json' --data '{"name":"Test","email":"chalda@marinade.finance","message":"hello","hp":"x"}'
# → expect 200, no email
```

**Gate:** all three curl checks pass.

## Phase 5 — GitHub Pages custom-domain switch

- [ ] Push Phase 3 changes (especially `public/CNAME`) to `main`. Wait for the deploy workflow to finish green.
- [ ] Settings → Pages → **Custom domain** → enter `psychoterapie-zarubova.cz` → Save.
- [ ] Wait for "DNS check successful" (auto-refreshes every ~30 s; can take up to a few minutes).
- [ ] Tick **Enforce HTTPS**. May be greyed out for up to ~15 min while GitHub provisions the Let's Encrypt cert — wait, don't proceed until it's both ticked and enforced.
- [ ] Verify:
  ```
  curl -I https://psychoterapie-zarubova.cz       # → 200
  curl -I https://www.psychoterapie-zarubova.cz   # → 301 to apex
  curl -I http://psychoterapie-zarubova.cz        # → 301 to https
  ```
- [ ] Open in a browser, check no mixed-content / cert warnings.

**Gate:** apex and www both serve HTTPS, cert valid, no warnings.

## Things to NOT do during launch

From `PLAN.md` §14, repeated here because they're the easiest mistakes to make under deadline pressure:

- **Don't `git push --force`** to main, ever.
- **Don't commit secrets.** `RESEND_API_KEY` lives in Wrangler / GH Secrets only. `.env` is gitignored.
- **Don't set CORS to `*`** on the Worker.
- **Don't put a trailing newline in `public/CNAME`** — GitHub Pages parses it strictly.
- **Don't remove `public/CNAME`** "to clean things up" — removing it on a deploy can revert the custom-domain setting.
- **Don't skip Resend domain verification.** Unverified domains will silently fail to deliver email to anyone who isn't the account owner.
- **Don't typo `ALLOWED_ORIGIN`** — it's the **site** URL (`https://psychoterapie-zarubova.cz`), not the Worker URL. Common gotcha.
